# Media assets — drop-in guide

## Swat's Up! (video)
- `swats-up-gameplay.mp4` — 1920x1080 or 1280x720, H.264, ideally <20MB
- `swats-up-poster.png` — 1280x720, poster frame shown before play / used as the home page thumbnail

## Cranes: ED Recovery (screenshots)
- `cranes-screen-1.png` — Home screen, portrait ~1170x2532 (or any consistent 9:19.5 ratio)
- `cranes-screen-2.png` — Journal screen, same ratio
- `cranes-screen-3.png` — Peer support screen, same ratio

Drop files here with these exact names. The placeholders in `index.html`
are marked with `REAL MEDIA GOES HERE` comments showing the exact markup
to swap in — no CSS or layout changes needed.
